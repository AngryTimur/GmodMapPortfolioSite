# Hammer Editor Portfolio

Готовый статический сайт-портфолио для Hammer Editor / Source Engine.

## Запуск

Никакой сборки не требуется. Откройте `index.html` в браузере.

Для более корректной работы локальных ресурсов рекомендуется запустить простой HTTP-сервер:

```bat
python -m http.server 8080
```

Затем откройте:

`http://localhost:8080`

## Где добавлять проекты

Редактируйте:

`js/projects.js`

Добавьте новый объект в массив `projects`.

Поля:

- `title` — название;
- `category` — ID категории;
- `published` — год публикации;
- `updated` — год обновления, можно убрать;
- `description` — описание;
- `image` — главное изображение;
- `screenshots` — массив изображений галереи;
- `tags` — массив тегов;
- `workshop` — URL Steam Workshop или `null`;
- `status` — `unavailable`, `soon`, `locked` или `concept`, если Workshop отсутствует.

## Где добавлять категории

Редактируйте:

`js/categories.js`

Например:

```js
{ id: "portal2", name: "Portal 2" }
```

После этого категория автоматически появится в UI, а её счётчик будет рассчитываться из массива проектов.

## Социальные ссылки

В `js/categories.js` измените `siteConfig.socials`.

Там же находится `donateUrl`.

## Изображения

Положите изображения проекта в отдельную папку:

`assets/projects/имя-проекта/`

Рекомендуется использовать WebP/JPG и оптимизировать большие исходники перед публикацией.

## Что уже реализовано

- категории из конфигурации;
- автоматические счётчики;
- фильтрация;
- автоматическая сортировка по дате;
- адаптивная сетка;
- hover-эффекты;
- модальное окно проекта;
- галерея;
- полноэкранный просмотр изображений;
- Steam Workshop / статусы;
- Esc и клик вне окна для закрытия;
- клавиатурная навигация карточек;
- lazy loading;
- `prefers-reduced-motion`;
- адаптивный footer и социальные ссылки.
